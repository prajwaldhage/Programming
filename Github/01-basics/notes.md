### Day 1: (22-12-2025)

- git init : Initialize the repository
- git add : Add the files to staging
- git status : status of staged and unstaged files
- git commit : commit the changes of the repo
- git remote : set an remote repository from cloud platform, e.g: github, gitlab
- git push : push the repository to cloud
