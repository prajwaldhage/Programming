RHEL Technical Overview (RH024) v10.0 Notes

# 1. Terminal Basics

Useful commands:

```bash
du -sh /home/prajwal
cd /path/to/directory
man <command>
```

Notes:
- `du -sh` shows disk usage for a directory.
- `cd` changes the current directory.
- `man` opens the manual page for a command.
- RHEL may include a command-line assistant such as RHEL Lightspeed, depending on the environment.
- Some features require a registered RHEL system with an active subscription.

# 2. Linux Filesystem Hierarchy

Linux starts with the root directory `/`.

| Path | Purpose |
| --- | --- |
| `/` | Root of the filesystem |
| `/home/<user>` | User home directories |
| `/etc` | Configuration files |
| `/var` | Variable data that changes often |
| `/usr` | User programs and shared files |
| `/usr/bin` | Executable binaries |
| `/usr/lib` | Shared libraries |
| `/tmp` | Temporary files |
| `/root` | Root user's home directory |
| `/boot` | Boot files |
| `/mnt` | Temporary mount points |
| `/run` | Runtime state information |
| `/dev` | Device files |

# 3. Basic File Management

```bash
ls
ls -l
ls -lh
ls -a
mkdir -p /path/to/newdir
cp file1 file2
cp -r dir1 dir2
mv oldname newname
rm file
rm -r directory
```

Notes:
- `-l` shows long format.
- `-h` makes sizes human-readable.
- `-a` shows hidden files.
- `mkdir -p` creates directories and parent directories if needed.
- `rm -r` removes directories recursively.

# 5. Users and Groups

Important files:
```bash
cat /etc/passwd
cat /etc/shadow
```

Common commands:
```bash
sudo -i
useradd username
passwd username
usermod -s /bin/zsh username
passwd -l username
```

Group commands:
```bash
groupadd groupname
groupdel groupname
groupmod --new-name newname oldname
usermod -aG groupname username
groups username
```

User account notes:
- Each user has a unique UID.
- Avoid reusing old UIDs in shared environments.
- Locking an account is often safer than deleting it.
- `userdel username` removes the user account but keeps the home directory by default.
- `userdel -r username` removes the home directory as well.
- The `wheel` group is commonly used for administrative access in RHEL.

Useful identity commands:
```bash
id username
find / -uid 1001 2>/dev/null
```

Best practice:
- Use a normal user account for daily work.
- Use `sudo` or `sudo -i` for administrative tasks.
- In larger environments, central identity management such as IdM or AD is preferred.

# 6. File Permissions

Every file has permissions that define who can read, write, or execute it.

| Permission | Meaning | Numeric |
| --- | --- | --- |
| `r` | Read | 4 |
| `w` | Write | 2 |
| `x` | Execute | 1 |

Example:
- `rwxr-xr-x` = owner can read/write/execute; group and others can read/execute.

Common commands:
```bash
ls -ld /path/to/dir
chmod 000 /path/to/dir
chmod 755 file
chmod 644 file
chown user file
chgrp group file
chown -R user:group /path/to/dir
```

Important notes:
- `ls -ld` shows permissions for a directory itself.
- A directory needs execute permission to be traversed.
- A directory needs read permission to list its contents.
- A directory needs write permission to create or remove files inside it.
- To run a program, execute (`x`) permission is required.
- The owner is the user who created the file.
- The owning group is based on the creator's primary group.
- `others` means anyone who is not the owner or in the group.

# 7. Managing Software and Updates

Check subscription status:
```bash
subscription-manager identity
subscription-manager register
```

Package management:
```bash
dnf search nodejs
dnf install -y nodejs
dnf update
```

Security and update information:
```bash
dnf updateinfo list
dnf updateinfo info RHSA-2025:10854
dnf update --security
dnf update --security --sec-severity=Important --sec-severity=Critical
```

Notes:
- `dnf` resolves dependencies automatically.
- `-y` answers yes to prompts.
- Updates come from Red Hat Errata.
- Common errata types:
  - `RHBA`: bug fix
  - `RHEA`: enhancement
  - `RHSA`: security advisory
- CVEs and CVSS scores are associated with security vulnerabilities.
- After updates, check whether a reboot is needed:
```bash
dnf needs-restarting -r
reboot
```

# 8. Networking

RHEL uses NetworkManager for networking.

Useful commands:
```bash
nmcli connection show
nmcli connection show <profile>
nmcli device status
ip a
ip route show
cat /etc/resolv.conf
```

Add a manual connection example:
```bash
nmcli connection add con-name datacenter type ethernet ifname enp7s0 \
  ipv4.method manual ipv4.address 192.168.1.114/24 \
  ipv4.gateway 192.168.1.1 ipv4.dns "192.168.1.1,8.8.8.8"
```

Delete a profile:
```bash
nmcli connection delete datacenter
```

Notes:
- `lo` is the loopback interface.
- `enp7s0` is an example interface name; your interface may differ.
- `nmtui` provides a text-based interface for NetworkManager.

# 9. Managing System Services with systemd

systemd manages services, sockets, timers, targets, and other units.

Install and test a web server:
```bash
sudo dnf install -y httpd
echo "hello world" | sudo tee /var/www/html/index.html
```

Manage the service:
```bash
sudo systemctl start httpd
sudo systemctl enable httpd
sudo systemctl enable --now httpd
sudo systemctl status httpd
```

Firewall rules:
```bash
sudo firewall-cmd --add-service http --permanent
sudo firewall-cmd --reload
sudo firewall-cmd --list-all
```

Other useful commands:
```bash
sudo systemctl restart httpd
sudo systemctl stop httpd
sudo systemctl disable --now httpd
```

Notes:
- `systemctl enable --now` starts the service and enables it at boot.
- `--permanent` makes firewall changes persistent.
- `firewall-cmd --reload` applies the updated rules.

# 10. Deploying an Application Runtime

Example workflow for a simple Node.js app:
```bash
dnf install -y nodejs
git clone <repo-url>
cd <repo-directory>
npm install
```

Create a systemd unit file:
```bash
sudo cp myapp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now myapp.service
sudo systemctl status myapp.service
```

Open the app port in the firewall:
```bash
sudo firewall-cmd --permanent --add-port 8080/tcp
sudo firewall-cmd --reload
```

This allows the application to run as a fully managed system service.

# 11. Image Mode with bootc

RHEL 10 introduces image-based deployment with `bootc`.

Useful commands:
```bash
ssh bootchost
bootc status
rpm -q httpd
bootc switch quay.io/rdacosta/bootc_httpd:2
reboot
```

Notes:
- A bootc image contains the full operating system.
- This makes upgrades more predictable.
- If something goes wrong, you can roll back to a previous image.

# 12. Insights Image Builder

A golden image is a clean, tested template for deployment.

Common workflow:
1. Open the RHEL console.
2. Go to Insights and create an image blueprint.
3. Choose the image format, such as `qcow2`.
4. Configure registration, packages, users, hostname, timezone, and networking.
5. Build the image.

Notes:
- Image Builder can create a consistent, reusable base image.
- You can include packages and users during the build process.

# 13. Insights Vulnerability Management

Insights helps identify vulnerabilities, policy issues, and misconfigurations.

Register the system:
```bash
sudo insights-client --register
```

Notes:
- The system must be registered and connected to Insights.
- Use Insights regularly and automate remediation when possible.

# 14. Cockpit (RHEL Web Console)

Cockpit is a web-based administration console for RHEL.

Enable Cockpit:
```bash
sudo systemctl enable --now cockpit.socket
```

Access:
- Open `https://<server-ip>:9090`

Cockpit can help with:
- System health and performance
- CPU and memory usage
- Storage management
- Networking
- Firewall rules
- Accounts and services
- Logs
- Containers and virtual machines
- SELinux and software updates

Install additional plugins:
```bash
dnf search cockpit-*
sudo dnf install cockpit-*
```
